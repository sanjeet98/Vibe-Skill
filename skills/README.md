# Agent Skills Directory

This directory hosts agent skill packages, blueprints, and reusable capability definitions for Antigravity.

Each skill package is structured with:

- `skill.yaml` / `skill.json`: Manifest declaring capabilities, triggers, and dependencies
- `scripts/`: Implementation scripts and handlers
- `templates/`: Code templates and codemod rules for AST scaffolding
- `tests/`: Automated unit and integration verification tests
